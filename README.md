# WeatherMapZ Frontend

React + Vite frontend for WeatherMapZ.

## Requirements

- Node.js 22 or newer
- npm

## Setup

```bash
npm install
cp .env.example .env
```

## Development

```bash
npm run dev
```

The development server runs on <http://localhost:5173>.

## Test

```bash
npm test
```

## Production Build

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```

## Environment

- `VITE_API_BASE_URL`: backend API base URL. Default local value: `http://localhost:3000/api`.
